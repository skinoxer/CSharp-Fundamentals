# 📦 Mini Warehouse Management System (C# Console)

یک پروژه کنسولی کامل برای مدیریت کالاها و انبار با تمرکز بر پیاده‌سازی اصول پایه‌ای و ساختارهای زبان C#.

## 🚀 قابلیت‌های برنامه (Features)
- **مشاهده کالاها:** نمایش تمام محصولات به همراه قیمت با مدیریت حالت انبار خالی.
- **افزودن محصول:** اعتبارسنجی قیمت (جلوگیری از قیمت منفی) و حذف فاصله‌های اضافه نام کالا (`Trim`).
- **جستجوی پیشرفته:** جستجوی حساس نبودن به حروف کوچک/بزرگ (`Case-insensitive`) با متدهای رشته.
- **محاسبه ارزش کل انبار:** استفاده از متد بازگشتی و محاسبات `LINQ`.
- **کنترل خطا و اعتبارسنجی ورودی‌ها:** جلوگیری از کرش کردن برنامه با `int.TryParse`.

## 🛠️ مفاهیم به کار رفته از C# (Topics Covered)
- انواع داده و متغیرها (`Data Types & Variables`)
- لیست‌های پویا (`List<T>`)
- حلقه‌های تکرار و پیمایش (`while`, `for`)
- ساختارهای تصمیم‌گیری (`switch-case`, `if-else`)
- متدها و توابع محلی (`Methods & Local Functions`)
- کار با متدهای رشته (`String Methods: Trim, ToLower, Contains`)
- کار با `LINQ` (`Sum`)
